Sta projekat demonstrira

  • Spring MVC arhitekturu: Controller - Service - Repository - Entity.
  • CRUD nad 5 glavnih tabela.
  • OneToMany relaciju: Category - Book.
  • ManyToMany relacije: Book - Author i User - Role.
  • Autentifikaciju i autorizaciju preko uloga.
  • Upravljanje HTTP sesijom preko Spring Security.
  • REST API za knjige koji moze da se dokumentuje u Postman-u.
